# 阶段 2：逐点绘制与顶点编辑验收

本阶段保留已有的 Enter 提交属性、80 μm 默认填充间距和独立宽高编辑。没有增加椭圆、文字或布尔工具，没有提交 Git。

## 启动

前端已构建。请先关闭旧应用，在项目根目录的 PowerShell 中手动执行：

```powershell
.\.venv\python.exe .\backend\scripts\run_desktop.py
```

## 逐点绘制

1. 按 P 或点击多边形工具。在工作区依次点击三个以上顶点，观察已绘制的折线、鼠标处的待连接线及左下角提示。
2. 点击首点或按 Enter 闭合。成功后应生成一个对象，继承当前默认加工参数，并回到选择工具；撤销一次即可撤回整个对象。
3. 绘制一个凹多边形，开启填充预览，检查凹入区域没有填充线。
4. 在草稿中按 Backspace、Ctrl+Z 或点击撤销，应只移除最后一个草稿点，不影响现有对象。草稿中的 Delete 不应删除任何已有对象。
5. 按 Esc 或切换到其他工具，草稿应取消，不增加撤销记录。未闭合草稿不写入项目文件。
6. 尝试仅有两个点就闭合、重复上一点、三个共线点或自交图形。应拒绝无效操作；闭合失败时保留草稿，可撤回点后继续修正。
7. 检查工作区外点击被拒绝，开启移动吸附后新增顶点按网格定位。缩放或用中键平移时，草稿应跟随世界坐标正确显示。

## 顶点拖动与精确输入

1. 选择新画的多边形，在属性面板点击“编辑顶点”。应隐藏整体缩放、旋转控制框，显示各顶点；选中顶点呈橙色。
2. 点击一个顶点但不拖动，图形和历史应不变化。拖动顶点时应实时显示有效预览，一次松开只产生一次撤销。
3. 在右侧修改“顶点局部 X/Y”，按 Enter 或离开输入框应提交；世界坐标应同步更新。局部坐标相对图形参考点，随图形旋转。
4. 将顶点拖成自交、退化或越界形状。无效位置显示红色标记，松开后拒绝修改、保留原图形，且不增加撤销记录。
5. 拖动有效预览时按 Esc，应退出编辑并恢复拖动前形状；之后松开鼠标也不能误提交预览。
6. 点击“完成顶点编辑”或按 Esc，应退出顶点编辑并保留对象选择。随后可以正常移动、缩放和旋转整个对象。

## 插入、删除、孔洞和分离部分

1. 编辑顶点时双击边，应在点击附近插入顶点；双击已有顶点不应重复插点。检查最后一个顶点连接首点的闭合边也可插点。
2. 选中一个顶点，点击“在所选顶点之后插入中点”，应在下一条边上插入并选中新点。
3. 按 Delete/Backspace 或点击“删除所选顶点”，应只删除该顶点。每个轮廓剩余三个顶点时禁止继续删除。
4. 在坐标输入框内使用 Backspace/Delete，应编辑文字，不能删除顶点或对象。
5. 打开 `fixtures/polygons-v2.lasertisch.json`，编辑旋转的带孔多边形。通过点击画布或面板轮廓选择器选中孔洞顶点，检查移动、插入和删除。孔洞移出外轮廓或与外轮廓接触时应拒绝修改。
6. 编辑“两个分离部分”，通过画布或面板切换到第二个部分，修改其顶点；第一个部分应保持不变。
7. 退出编辑后检查加工预览，保存后重开，确认形状、孔洞、加工参数和顺序均正确。分别导出 CSV 和 DBD。

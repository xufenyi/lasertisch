# 阶段 5：字体与文字轮廓核心验收

本阶段提供默认字体、系统字体枚举、基本单行排版、文字转多边形、跨前后端数据契约和加工验证。文字工具及字体选择界面属于阶段 6；当前界面没有文字按钮。

## 启动

可以手动双击仓库中的 `dist/LaserTisch.exe`。也可使用当前 Anaconda 目录环境启动源码版：

```powershell
.\.venv\python.exe .\backend\scripts\run_desktop.py --debug
```

## 手动检查

1. 打开 `fixtures/text-outlines-v2.lasertisch.json`，确认能看到八组文字：`AB 8`、`中文 回`、`한글`、`Üé ß`、`AV fi`、`B8`、`2026`、`口回`。
2. 放大查看弯曲部分，确认实际轮廓由直线小段组成，没有方框替代字符；`B`、`8`、`回`等内部孔洞应完整。
3. 打开加工路径预览。样例默认先填充后轮廓、扫描间距 0.2 mm；填充应逐行往返，跳过字内孔洞，字间与孔洞中的连接应显示为空行程。可修改填充角度再检查。
4. 选中一组文字，平移、旋转或修改尺寸，检查预览随之更新；撤销和重做应正常。
5. 另存项目并重新打开，确认轮廓一致；分别导出 CSV、DBD，确认可以成功保存。样例是普通多边形，可以编辑顶点，暂时不能修改原文字内容或字体。

## 自动覆盖的检查

- 默认字体校验和、版权与许可资源；系统字体扫描、字体集合多个字面、缺字和字体被替换后的错误处理。
- 二次和三次曲线离散误差、复合字形、组合重音、空格宽度、重叠字形合并、孔洞、细小文字及顶点上限。
- UTF-8 桥接、快照来源和几何哈希、过期响应拒绝、不依赖字体的多边形快照读取、填充及设备导出。
- wheel 与 Windows 桌面包的默认字体资源和自检。

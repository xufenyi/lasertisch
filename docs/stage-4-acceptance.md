# 阶段 4：布尔运算验收

已验收的椭圆功能已保存为本地提交 `4b53df9`。本阶段的布尔功能尚未提交 Git，没有开始文字开发。

## 启动与示例

关闭旧应用后，在项目根目录的 PowerShell 中手动启动：

```powershell
.\.venv\python.exe .\backend\scripts\run_desktop.py
```

打开 `fixtures/booleans-v2.lasertisch.json`。项目包含四组对象：重叠 A/B、孔洞外框/内框、分离 A/B、椭圆 A/矩形 B。

## 基本操作与预览

1. 在右侧对象列表先选“重叠 A”，再按住 Ctrl 点击“重叠 B”。属性面板应显示布尔运算，明确列出 A/B 名称。
2. 选择并集，点击“预览结果”。绿色显示结果，原对象淡化；此时对象数量、保存状态和撤销历史不应改变。
3. 预览期间缩放、用中键平移，检查结果跟随世界坐标。原对象不能直接拖动，加工路径应暂时隐藏。点击“取消预览”后原显示和交互恢复。
4. 点击“应用运算”，原对象替换为一个普通多边形。检查一次撤销能恢复两个原对象，重做能恢复结果。
5. 分别预览并应用交集、减除 A − B，检查形状；交换 A/B 后再减除，结果区域及加工参数来源应改变。

## 孔洞、分离部分和椭圆

1. 选择“孔洞 外框”为 A、“孔洞 内框”为 B，执行减除。结果应为一个带孔多边形；选择编辑顶点可编辑其孔洞。
2. 选择“分离 A”为 A、“分离 B”为 B，执行减除。结果应是包含两个分离部分的一个多边形对象。
3. 对“椭圆 A”和“矩形 B”执行三种运算，结果应使用椭圆当前的 64 边几何；可先修改边数，再重新预览比较结果。
4. 应用后开启加工预览，检查填充避开孔洞和分离间隙，轮廓、填充模式可正常切换。

## 参数与加工顺序

1. 示例每组 A/B 加工参数不同，应出现继承提示。应用后结果应继承 A 的方式、速度、填充参数和方向；交换 A/B 后继承来源跟随改变。
2. 调整对象加工顺序，使 B 位于 A 前面或两者之间夹有其他对象，再应用。结果应处于 A 原来的相对位置，其他对象相对顺序不变。
3. 勾选“保留原对象”后应用。A/B 应保留名称、形状和加工参数，结果作为新对象插在 A 后面。注意原对象仍参与加工；不需要重复加工时将其设为“不加工”。

## 空结果、相切与错误处理

1. 选择相互分离的“重叠 A”和“孔洞 外框”做交集。预览应明确提示空结果；默认不允许应用，更不能自动删除对象。
2. 勾选“确认移除这两个原对象”后应用，应删除两者，一次撤销可恢复。取消预览应保持原对象。
3. 空结果下勾选“保留原对象”，应禁止应用并提示无需应用空结果。
4. 用同样大小、同样位置的两个矩形测试完全重合；并集和交集保持该区域，减除为空。
5. 测试只共享一条边或一个点的矩形。交集为空；并集分别合并为区域或保留两个点接触的分离部分。
6. 选择中含有线段、超过两个对象，或包含锁定/隐藏对象时，不允许请求运算，并给出原因。
7. 如果复杂相切结果违反多边形规则，应提示失败并保留原对象；微调图形后可以重新计算。

## 失效处理、保存与导出

1. 预览后修改加工参数、重命名对象、改选其他对象、切换工具或撤销，旧预览应失效，不能继续应用旧结果。
2. 如果计算仍在进行，取消、交换 A/B 或切换运算后，旧响应不能覆盖新预览，也不能自动修改项目。
3. 保存后重开，结果应是可编辑的普通多边形，孔洞、分离部分、参数和加工顺序保留。未应用的预览不应写入项目文件。
4. 分别导出 CSV 和 DBD，检查现有矩形、线段、多边形和椭圆功能正常。

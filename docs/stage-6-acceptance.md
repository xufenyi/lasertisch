# 阶段 6 与短线段处理联合验收

本阶段把文字创建、编辑、项目保存和短边处理接入 GUI。请手动启动仓库中的 `dist/LaserTisch.exe`；也可运行当前虚拟环境的源码版：

```powershell
.\.venv\python.exe .\backend\scripts\run_desktop.py --debug
```

## 创建、预览与编辑

启动后先不要打开文字工具，等待数秒再进入编辑，字体列表应直接可用且没有“已跳过字体”提示。另一次启动后立即点击文字工具，此时不应在项目名称上方显示字体进度。点击画布进入文字编辑后，如果字体尚未读完，字体选择区域下方应显示“正在读取系统字体…”，完成或取消编辑后提示消失。关闭并再次编辑文字不应重新扫描，手动刷新仍可重新读取目录。

顶部绘图工具应为一个连续组，从左到右排列为线段、矩形、椭圆、多边形、文字。新建按钮左侧应有竖分隔线，撤销左侧与重做右侧不再有竖分隔线。测试 Ctrl+N 新建、Ctrl+O 打开（macOS 使用 Command），未保存项目仍应先确认是否放弃更改。

1. 按 T 或选择文字工具，在工作区左侧点击一个位置。在右侧输入 `中文 AB8 한글 Üé`，选择随附默认字体，字号可用 5 mm，点击“预览轮廓”。绿色结果应出现在所点位置，项目此时没有新增加工对象。
2. 点击“应用文字”，确认对象列表新增文字，按一次撤销应完整移除，重做应恢复。取消预览应不新增对象或历史记录。
3. 选中文字，点击“编辑文字”，修改内容、字体和字号。系统字体列表可搜索；首次扫描可能需要数秒，可点击刷新重新读取。若某字体缺字，应看到明确错误，不应悄悄换字体。
4. 修改预览参数后，“应用文字”应立即不可用，须重新预览。生成期间继续修改输入或取消，迟到的结果不能覆盖新输入或应用到文档。
5. 修改基线位置、旋转角度，或拖动/旋转画布中的文字。大小通过字号调整。检查撤销、重做和原有加工顺序、加工参数不丢失。

## 短线段处理

1. 打开 `fixtures/editable-text-v2.lasertisch.json`。前两组 `AB 8` 分别用于默认精度与较宽松精度的对照；其他样例提供中、韩文和带重音字母。
2. 编辑一组文字，将短线段合并目标设为 0，预览并记录顶点数、最短边；再设为 0.2 mm，保持字号和误差一致，重新预览。
3. 允许的误差很小时，顶点数可能不变。若想进一步降低密度，可同时试用 0.02 或 0.05 mm 的轮廓误差，放大比较圆弧、尖角、细笔画和字内孔洞。
4. 未达目标的边应显示数量并标红。它们必须继续留在轮廓和导出中，不能以断开轮廓的方式跳过。检查闭合处的边也包含在统计中。
5. 把目标设为明显过大的值，确认程序仍保护孔洞和闭合轮廓，并提示仍有短边；超出工作量限制时保留未处理线段并提示。

短边目标是尽力合并条件，不是设备硬性下限。最大轮廓误差指微米取整之前的逼近约束，最终 1 µm 网格和旋转取整还会带来小量误差。统计使用当前世界坐标，旋转后最短边及未达目标数量可能在临界值附近变化。该设置只处理文字轮廓，不改变既有填充短段筛选规则。

## 保存、缺字与缺失字体

1. 保存含文字的项目并重开，内容、字体身份、字号、误差、目标、位置、加工参数和轮廓应一致。
2. 打开 `fixtures/text-missing-font-v2.lasertisch.json`。这是用测试身份模拟缺失字体，不需要卸载电脑字体。文字仍应显示、填充并导出。
3. 编辑此文字，应提示原字体不在目录中；尝试原字体重新生成应报错。明确选择随附默认字体后才可重新生成和应用。取消编辑应保留原轮廓。

## 加工、转换及布尔

1. 开启文字加工路径预览，设置填充后轮廓、不同扫描角度和间距，确认 B/8/回等孔洞不被填满，跨孔洞和字间的空行程关闭激光。分别导出 CSV、DBD。
2. 选择文字与一个矩形，测试并集、交集和有顺序的减除。结果应为普通多边形；撤销应恢复可编辑文字。
3. 将文字“转换为普通多边形”，检查可拉伸和编辑顶点，转换后不再有内容/字体编辑按钮；撤销应恢复文字来源和原轮廓。

当前项目仍为版本 2，增加 `text` 对象类型；支持旧的版本 1 和版本 2 图形项目。较早程序不能读取新文字类型，可先转换为普通多边形后保存。

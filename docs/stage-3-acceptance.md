# 阶段 3：椭圆与正圆验收

已验收的多边形功能已保存为本地 Git 提交 `7bb330e`。本阶段新增椭圆和正圆；椭圆阶段的改动尚未提交 Git，也未开发布尔或文字功能。

## 启动

前端已构建。关闭旧应用后，在项目根目录的 PowerShell 中手动执行：

```powershell
.\.venv\python.exe .\backend\scripts\run_desktop.py
```

## 绘制

1. 按 E 或点击椭圆工具，在工作区向四个方向分别拖动，松开后应生成矩形区域内接椭圆的多边形近似，并回到选择工具。
2. 按住 Shift 拖动，应绘制正圆，宽高相等；检查在拖动中按下或松开 Shift 后预览变化。
3. 默认边数为 64，完成一次绘制只产生一次撤销；继承当前默认加工参数。
4. 开启移动、缩放吸附，检查绘制的起点和尺寸吸附。拖动过程中按 Esc 或切换工具，应取消预览，不生成对象。
5. 单击不拖动，或生成微米网格上无法表示的极小形状，应拒绝创建并给出提示。

## 参数、变换与加工提示

1. 选中椭圆，修改中心 X/Y、宽高、角度和边数，按 Enter 或离开输入框提交。
2. 将边数依次改为 3、5、16、64、256，观察形状变化；再改回 64，应从原参数重新生成，中心、生成尺寸和角度保持不变。
3. 3–1024 之外的边数、小数边数、越界或退化参数应被拒绝，实际对象和历史保持不变；修正输入后可以继续编辑。
4. 低边数时，控制框和宽高仍表示生成矩形。实际多边形包围盒可能较小，控件不应在一次无变化的点击后改变尺寸或位置。
5. 拖动移动、缩放和旋转椭圆；与矩形、多边形一起多选移动，检查图形关系和撤销重做。
6. 确认面板显示增加边数的精度与加工提示、顶点数和最短轮廓边长。可将尺寸改为约 1 × 1 mm、64 边，观察短于 0.1 mm 的轮廓边提示。提示不会自动删除边或降低边数。

## 转换、保存和导出

1. 点击“转换为普通多边形”，形状、位置、名称、加工参数和顺序应保持不变；边数输入框消失，出现“编辑顶点”。
2. 编辑转换结果的顶点；撤销可恢复修改，继续撤销转换操作应恢复可调整边数的椭圆。
3. 打开 `fixtures/ellipses-v2.lasertisch.json`，应看到 32 边椭圆、64 边正圆、5 边近似和 256 边近似四个对象。
4. 开启加工预览，分别测试轮廓、蛇形填充、填充后轮廓和轮廓后填充，确认路径跟随实际多边形。
5. 调整边数、尺寸和旋转后保存，关闭重开；参数、形状、加工顺序应保留，并仍能修改边数。
6. 分别导出 CSV 和 DBD；同时打开之前的 v1/v2 矩形、线段和多边形项目，检查原有功能正常。

# 测试与验收

[开发者入口](README.md) · [架构](architecture.md) · [开发协作](development.md)

本清单按当前功能组织，替代原来的六份阶段验收记录。自动测试检查算法、契约和状态；桌面交互与平台运行仍由维护者手动验收。

## 自动检查

从仓库根目录执行。Windows 示例使用 Conda 目录环境；标准 venv 改用 `.venv\Scripts\python.exe`。

```powershell
.\.venv\python.exe -m pytest .\backend\tests -q
npm.cmd --prefix .\frontend test
npm.cmd --prefix .\frontend run build
.\.venv\python.exe .\backend\scripts\run_desktop.py --self-test
```

Linux / macOS：

```bash
.venv/bin/python -m pytest backend/tests -q
npm --prefix frontend test
npm --prefix frontend run build
.venv/bin/python backend/scripts/run_desktop.py --self-test
```

若系统临时目录不可写，可为 pytest 指定仓库内的独立目录，例如 Windows 的 `--basetemp .\.pytest-tmp\local-check`。该目录会被 pytest 重建，必须使用专门的临时路径。

修改契约后，用同一虚拟环境执行 `backend/scripts/export_schemas.py`，检查生成差异和两端解析器。构建和测试命令可能生成缓存，均由 `.gitignore` 排除。

## 通用交互

按[开发者入口](README.md#桌面运行)构建前端并手动启动应用。测试项目建议另存，避免覆盖基准样例。

- [ ] 顶部绘图组顺序为线段、矩形、椭圆、多边形、文字；新建和撤销左侧有分隔线，重做右侧无分隔线。
- [ ] 新建、打开、保存、工具切换及撤销重做快捷键有效；有未保存修改时，新建和打开先确认。
- [ ] 输入有效数值后 Enter 或离开输入框提交；输入法组词中的 Enter 不误提交，输入框内 Delete/Backspace 不删对象。
- [ ] 工作区、负坐标、缩放、中键平移、标尺、移动和缩放吸附正常，多选移动保持相对位置。
- [ ] Ctrl/Command+C 复制单个和多个对象，Ctrl/Command+V 粘贴，Ctrl/Command+D 重复；输入框中的复制粘贴仍编辑文字，工具栏按钮状态与快捷键一致。
- [ ] 粘贴和重复候选随光标整体移动并保留相对位置；网格吸附、滚轮缩放和中键平移正常，预览不修改项目、不增加历史且不触发候选加工路径。
- [ ] 合法单击一次创建整组并追加固定加工顺序，一次撤销移除整组；Esc 完全取消。四边越界显示红色且点击不创建，整组大于工作区时明确拒绝。
- [ ] 线段、旋转矩形、不同边数椭圆、含孔/分离多边形和可编辑文字均可复制；新 ID 唯一，名称、文字来源及加工参数保持不变。同一项目复制保留显示/锁定状态，跨项目粘贴恢复显示、解锁。
- [ ] 对象列表眼睛和锁按钮状态清晰；隐藏不影响加工和导出，锁定后画布、属性、加工参数、删除及布尔修改均被阻止，重命名、复制和排序仍可用。
- [ ] 显示/锁定切换不增加历史、不标记未保存且不写入项目文件；新建、打开或重启后全部显示并解锁，旧文件中的对应字段可读取但被忽略。
- [ ] 画布拖动和加工顺序拖动都只产生一次撤销；三横线排序柄可跨多项移动，取消或原位放下不增加历史。删除和重做正常，越界或退化输入保留原对象。
- [ ] 五种语言切换后，主要操作、字段及错误提示可读。

## 多边形与顶点

- [ ] 打开多边形样例，四个对象分别为 5 顶点普通形、6 顶点凹形、旋转 15° 的带孔形和包含两个分离部分的对象；孔洞和间隙不填色。
- [ ] 修改位置、局部宽高和旋转，孔洞同步缩放；宽高独立调整，一次撤销恢复。
- [ ] P 逐点绘制，点击首点或 Enter 闭合，成功后返回选择工具；凹多边形可加工。
- [ ] 草稿中 Backspace/Ctrl+Z 仅撤回上一点，Delete 不删已有对象；Esc 或切换工具取消且不增加历史，草稿不保存。
- [ ] 两点、共线、自交、重复点及越界输入被拒绝，闭合失败后仍可修正；缩放和平移不改变草稿世界位置。
- [ ] 顶点可选择、拖动、精确输入，单纯点击不增加历史；无效拖动标红并在松开后恢复，拖动中 Esc 取消。
- [ ] 双击边（含闭合边）插点，双击已有顶点不重复插入；面板插中点和删顶点有效，三顶点环禁止再删。
- [ ] 孔洞和不同分离部分可单独选择编辑，孔洞移出或接触外环被拒绝；退出编辑后恢复整体变换。

## 椭圆与正圆

- [ ] E 向各方向拖动生成内接椭圆，Shift 约束正圆，拖动中按下/松开 Shift 更新预览；Esc 取消。
- [ ] 默认 64 边，修改 3、5、16、64、256 边后从参数重新生成；非整数和范围外边数被拒绝。
- [ ] 低边数时控制框仍表示生成矩形，单击控制点不改变参数；极小尺寸退化时明确拒绝。
- [ ] 位置、尺寸、旋转、吸附和多选移动正常；面板显示精度与加工提示、顶点数和最短边。
- [ ] 转换为普通多边形后外形、ID、加工参数和顺序保留，可编辑顶点；撤销恢复可调椭圆。

## 布尔运算

- [ ] 恰好两个闭合对象显示 A/B；并集、交集、A−B 和交换 A/B 的结果正确，文字也可参与，线段不可参与。
- [ ] 预览为绿色、原对象淡化，不改变项目和历史；缩放、平移有效，加工路径暂时隐藏，取消恢复原状态。
- [ ] 应用生成普通多边形，一次撤销恢复全部；孔洞、分离部分和椭圆当前边数正确参与计算。
- [ ] 结果继承 A 参数和加工位置，其他对象相对顺序不变；保留原对象时结果在 A 后，原对象仍参与加工。
- [ ] 分离交集、完全重合减除等空结果默认不能应用；明确确认才删除 A/B；保留原对象时不应用空结果。
- [ ] 边接触、点接触和完全重合符合面积语义；不合法相切结果报错并保留原对象。
- [ ] 锁定、隐藏、含线段或超过两个对象的选择不能计算。
- [ ] 修改参数、名称、选择、工具、项目或撤销后旧预览失效；取消或计算中改变输入后，迟到响应不可应用。

## 文字、字体与短线段

- [ ] 启动时静默扫描系统字体；立即点击 T 不在项目名称附近显示进度。点击画布进入文字编辑后，尚未完成时才在字体区下方显示等待状态。
- [ ] 字体扫描完成或取消编辑后提示消失；再次编辑复用目录，手动刷新有效，无“已跳过字体”提示或已知元数据诊断刷屏。
- [ ] 输入 `中文 AB8 한글 Üé`，用默认字体预览并应用；预览不新增对象，应用一次撤销可移除，取消不改文档。
- [ ] 系统字体可搜索；缺字明确报错，不替换字体。内容、字体、字号、基线和旋转可再次编辑，保留对象参数和顺序。
- [ ] 改动输入立即清除旧预览，须重新预览才能应用；生成中取消或改变输入，旧响应不覆盖新状态。
- [ ] 比较短边目标 0 与 0.2 mm，记录顶点、最短边和未达目标数量；精度很高时允许顶点数不变。
- [ ] 试用 0.02/0.05 mm 误差与较大目标，检查尖角、细笔画、闭合边和孔洞；受保护短边保留并标红，不能断轮廓。
- [ ] 统计包括闭合边，基于当前世界坐标；旋转后临界值附近可有微米量化差异。短边合并不改变填充短段规则。
- [ ] 模拟缺失字体项目仍能显示和加工；重新生成须明确选择可用字体，取消保留原轮廓。
- [ ] 转换为普通多边形后可拉伸和编辑顶点，不能编辑内容/字体；撤销恢复来源与轮廓。

## 加工、文件与兼容

- [ ] 对多边形、椭圆、文字分别测试轮廓、填充及两种组合模式，改变扫描角度、间距和轮廓方向。
- [ ] 填充逐行往返，跳过凹入空白、字内孔洞和分离间隙，连接为空行程；短轮廓边仍保留。
- [ ] 线段加工方向和对象顺序不被优化改变；每次导出先关闭激光跳转原点，结束停在最后目标点。
- [ ] 保存后重开，图形、孔洞、参数和加工顺序一致；文字内容、字体身份、精度、目标及固定轮廓一致；工作区显示与锁定状态不进入文件。
- [ ] v1 样例打开后几何不变，另存为 v2，原文件不被迁移操作直接修改。
- [ ] 含旧类型的 v2 项目可用；未应用预览、草稿和编辑模式不进入保存文件。
- [ ] CSV 与 DBD 均能通过对话框保存；取消打开、保存或导出不产生错误文件。

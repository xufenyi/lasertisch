# CAM 行为契约

## 输入

CAM 接收已通过 `ProjectDocument` 验证的规范几何。开放线段和封闭区域必须走不同
路径：线段不参与区域布尔运算，区域可以产生轮廓和蛇形填充。

## 输出

CAM 输出 `ToolpathPlan`，其中：

- `inputRevision` 用于阻止过期结果覆盖新文档。
- `preamble` 恰好包含一个到 `(0, 0)` 的 `InitialJump`。
- `tasks` 顺序与项目 `processingOrder` 一致。
- 每段都有明确起点、终点、速度、Laser 状态、来源实体和任务 ID。

Travel 必须显式设置 `laser=off`；Contour、Hatch 和 OpenLine 必须显式设置
`laser=on`。任何零长度运动段均为错误。

## 轮廓

- 外环和每个孔洞都生成独立闭合轨迹。
- 每个环包括从最后一个顶点回到第一个顶点的实际 Mark 段。
- 默认顺时针；对象属性可改为逆时针。
- 所有环都使用同一方向规则，不依赖 Shapely 环的内部方向。
- 不做光斑、刀路或轮廓内外偏置。

## 蛇形填充

1. 在世界坐标下构造无限平行扫描线族。
2. 与有效加工区域求交。
3. 只提取 LineString/MultiLineString 中量化后不少于 100 µm 的线段。
4. 一行内的多个分离交集必须分别成为 Mark，中间插入 Travel。
5. 相邻扫描行交替方向。
6. 不允许跨过孔洞或空白区域时保持激光开启。

点接触和零长度 GeometryCollection 成员不产生运动。一条扫描线若与边界重合，
重合得到的有效线段仍按普通 Mark 段处理。

## 顺序

- 对象之间不得重排。
- 线段不得翻转端点。
- 模式内部严格按 `contour`、`fill`、`fill_then_contour`、
  `contour_then_fill` 的定义输出。
- 单对象内部允许选择轮廓起点，但不能改变用户可观察的对象顺序。

## 设备映射

设备坐标与世界坐标相同。设备适配层把 Travel 变为绝对 `jump`，把 Mark 变为
绝对 `mark`。设备已知语义是从上一条命令的位置运动至本条目标位置；`mark`
期间激光开启。

软件不限制设备分辨率、速度范围或加速度。软件仍需拒绝超出工作区的坐标，并
保持所有速度和单位显式。

# 多语言包规范

## 支持语言

- `zh-CN`：默认及回退语言
- `en`
- `fr`
- `de`
- `ko`

语言选择是用户界面设置，不进入项目文档。

## 文件格式

语言包是 UTF-8 JSON，包含 `_meta` 和 `messages`。文件名必须与 `_meta.locale`
一致，版本初始为 1。所有官方语言包必须拥有与 `zh-CN` 完全相同的消息键。

消息内容是纯文本，不解释为 HTML。缺少或损坏的外部翻译项回退到内置中文。

## 加载和覆盖

应用内置一份完整语言包以保证离线启动。启动时可从用户配置目录读取同名文件
覆盖内置文本：

- Windows：`%APPDATA%/LaserTisch/locales`
- Linux：`~/.config/LaserTisch/locales`
- macOS：`~/Library/Application Support/LaserTisch/locales`

文件可用普通文本编辑器修改。React 使用 `react-i18next` 注册资源并调用
`changeLanguage`，因此切换后无需重启。

## 稳定标识

以下内容永不翻译：

- JSON 字段名和 `schemaVersion`
- 对象 ID
- 枚举持久化值
- Bridge 错误代码
- `mm`、`µm`、`mm/s` 等协议单位标识

数字输入可接受 `.` 和当前语言的小数分隔符，但进入规范模型前必须转换为精确
十进制字符串，再解析成整数 µm。

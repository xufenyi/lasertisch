# 阶段 1：Python 几何与 CAM 实现

状态：完成。

## 实现范围

- 规范矩形、线段和带孔/多 part 多边形转换为 Shapely。
- 所有 Shapely 结果在明确边界使用 0.001 mm 精度网格。
- 无效、自相交或在精度缩减后消失的区域被拒绝，不自动修复。
- 外轮廓和孔洞均可按顺时针或逆时针生成显式闭合路径。
- 轮廓起点选择距离当前点最近的现有顶点。
- 世界原点锚定的任意角度蛇形扫描。
- 凹多边形、孔洞、GeometryCollection 和多个分离区域的线段提取。
- 量化后小于 100 µm 的扫描段过滤。
- 对象强制顺序、线段强制端点方向和加工模式组合。
- 初始未知位置到世界原点的显式 `InitialJump`。
- Mark 之间所有空白、孔洞和跨对象移动都输出显式 Travel。

## 验证重点

自动测试覆盖：

- 旋转矩形中心和顺时针角度。
- 无效多边形拒绝。
- 凹多边形填充不跨越缺失区域。
- 水平、旋转对象及任意角度的世界坐标填充。
- 边界扫描线、0.1 mm 最小长度、孔洞和多区域。
- 外环和孔洞同方向且实际闭合。
- InitialJump、Travel/Mark 激光状态、对象顺序和线段方向。
- 参考 CSV/DBD 的逐字节黄金回归。

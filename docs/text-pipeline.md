# 文字与字体管线

[开发者入口](README.md) · [架构](architecture.md) · [测试与验收](testing.md)

文字在项目中保留可编辑来源与固定多边形轮廓。下面说明重新生成轮廓时的处理过程，以及不依赖本机字体重开项目的约束。

## 字体目录与身份

`text/fonts.py` 枚举本机 TTF、OTF、TTC、OTC；默认字体随软件分发，始终列在首位。字体标识为文件 SHA-256 加集合字面索引，不依赖名称或路径；显式选择的字体不可用、文件内容改变或缺字时返回错误，不静默替换。仅支持有单色轮廓的字体，彩色字体不列入目录。扫描结果可刷新，平台路径和注册表只在后端读取。

## 单行排版与轮廓离散

`text/outlines.py` 用 HarfBuzz 执行基本单行排版，用 FontTools 读取字形及复合部件。内容上限为 256 个 Unicode 码点，拒绝换行、制表符和控制字符，保留普通空格，不提供字间距或高级排版参数。字号表示 EM 大小，不表示可见包围盒高度；局部原点为排版起始处基线，Y 轴向上，字形允许伸出基线或原点。

字体中的二次、三次曲线只在转换过程读取，经自适应细分为直线段。默认容差 5 µm，可选 1–1000 µm，指最终微米取整之前的弦逼近误差；最终仍遵守 1 µm 网格。非零绕数规则恢复字内孔洞，再合并重叠字形，避免重复加工。细分和最终快照最多 100000 个顶点，过细文字拒绝生成，取整导致部件或孔洞数改变时返回提示。CAM 直接使用多边形，已有蛇形扫描跳过孔洞，空行程关闭激光。

## 来源、快照与持久化

`domain/text.py` 的独立 `TextOutlineSnapshot` 保存来源、解析后的字体身份、字号/容差、生成器/引擎版本、排版前进宽度、字形数以及固定多边形快照；源信息和几何各有规范 UTF-8 JSON 的 SHA-256。读取快照不查字体、不重新排版。前端对 API 快照做线性结构与哈希检查，后端完成拓扑校验；项目导入仍使用独立的完整几何校验。

`font_catalog`、`text_outline` 两个只读应用接口使用版本 1 请求/响应和独立 Schema。文字响应回传文档修订号，前端拒绝旧响应、源参数不一致及替换字体。独立快照保留来源和几何哈希；项目中的 `TextEntity` 则直接保存 `text` 来源、`parts` 固定轮廓、生成器和引擎版本，以及位置/旋转和加工参数。导入项目同步校验来源结构及完整轮廓拓扑，不读取字体，也不重新生成。

`TextEntity` 是多边形几何的特化，加入现有版本 2 判别联合，版本 1 拒绝文字。CAM、布尔运算只使用固定轮廓；布尔结果及显式转换结果是普通多边形。文字允许刚性平移/旋转，修改字号须重新生成，禁止画布自由缩放以免来源与轮廓含义不一致；转换为普通多边形后可以自由拉伸和编辑顶点。

## 短线段合并

`shortSegmentTargetUm` 默认为 0，启用时在所有字形合并后、最终取整前处理闭合轮廓。原有控制点到弦的距离判据给出二次曲线不超过半容差、三次曲线不超过四分之三容差的误差上界；保留四分之一容差用于短边合并，避免把完整误差预算使用两次。合并比较替换弦与原始整段点链的偏移，不能只比较最后删除的点。每次修改检查有效性、环方向、环间边界分离，保留每个孔洞和分离部分；预算不足或达到工作量限制就保留短边并返回提示。它是软目标，不能保证每条边达到下限，不处理填充段。

## 编辑会话与启动预读

前端文字编辑会话与文档修订绑定，独立保存候选轮廓。输入改变即清除预览并使请求失效；应用时再次检查会话、修订、边界和拓扑，以一次历史操作创建或替换文字，保留原对象 ID、名称、加工参数和加工位置。预览淡化原轮廓、显示绿色候选和红色未达目标边，暂停加工路径叠加；取消不修改文档。字体目录查询失败时仍保留已有字体选项；缺失原字体不静默替换。

`useStartupFontCatalog` 在应用挂载时静默启动目录读取；生产环境桥接未注入时等待 `pywebviewready`。`fontCatalogStore` 缓存目录、默认字体身份、读取状态与正在执行的请求，避免 StrictMode、重复就绪事件和多次进入文字工具导致重复扫描。字体编辑面板只订阅共享结果，刷新复用同一状态。正在读取时，仅在文字编辑面板的字体选择区域下方显示进度，单纯选中文字工具时不显示；个别字体跳过信息不返回用户提示。

## 字体诊断与静默策略

`text/diagnostics.py` 只对 FontTools 的 `_h_e_a_d` 和 `_n_a_m_e` 两个具体日志源安装过滤器，屏蔽已确认可恢复的 created/modified 时间戳以及 name 表 stringOffset 诊断。过滤器幂等，不改变全局日志级别，带异常堆栈的记录及其他消息继续保留；不修改系统字体文件。

不支持或无法读取的个别字体在目录扫描中静默跳过，不返回“已跳过”提示。用户明确请求生成的字体不可用或缺字时仍返回错误，不能以扫描静默为由换用其他字体。

## 实现定位

| 位置 | 职责 |
| --- | --- |
| `backend/src/lasertisch/domain/text_source.py` | 项目与生成请求共用的来源参数 |
| `backend/src/lasertisch/domain/text.py` | 字体目录、轮廓请求响应、快照与哈希 |
| `backend/src/lasertisch/text/` | 字体扫描、排版、离散、短边与诊断 |
| `backend/src/lasertisch/application/text_api.py` | 纯数据应用接口 |
| `frontend/src/state/fontCatalogStore.ts` | 共享目录、状态和请求去重 |
| `frontend/src/planning/useStartupFontCatalog.ts` | 启动预读及桌面桥接就绪等待 |
| `frontend/src/components/TextEditorPanel.tsx` | 创建、参数输入、预览和应用 |
| `frontend/src/components/TextGeometryForm.tsx` | 已有文字的位置、编辑入口与转换 |
| `frontend/src/domain/text.ts` | 前端来源解析与快照校验 |
| `frontend/src/domain/textGeometry.ts` | 世界坐标最短边与未达目标统计 |

默认字体和独立许可见[字体说明](../backend/src/lasertisch/assets/fonts/README.md)。升级字体前阅读[资源维护约定](development.md#示例与资源)。

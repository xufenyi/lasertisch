# 阶段 1：多边形基础验收

本阶段已加入多边形显示、选择、移动、缩放、旋转、属性编辑、加工预览和导出，以及版本 1 到版本 2 的项目迁移。逐点绘制和顶点编辑属于下一阶段，工具栏暂时没有新增绘制按钮。

## 启动

当前电脑的项目独立环境位于 `.venv/`，使用 Python 3.12；前端已经构建。请在项目根目录的 PowerShell 中执行：

```powershell
.\.venv\python.exe .\backend\scripts\run_desktop.py
```

如需重新构建前端：

```powershell
npm.cmd --prefix .\frontend run build
```

由用户手动启动应用进行验收。此阶段不要求生成单文件发行包。

## 打开示例

在应用中打开 `fixtures/polygons-v2.lasertisch.json`，应看到四个对象：

| 对象 | 预期 |
| --- | --- |
| 普通多边形 | 左上方，5 个顶点 |
| 凹多边形 | 右上方，6 个顶点，凹入区域为空 |
| 带孔多边形 | 左下方，旋转 15°，1 个孔洞、8 个顶点 |
| 两个分离部分 | 右下方，2 个部分、8 个顶点，整体作为一个对象选择 |

画布轮廓和选中效果应包含孔洞；孔洞和部分之间的空白不应填色。可从右侧对象列表选择整个多边形。示例初始关闭移动和缩放吸附，以便观察连续变换。

## 编辑与历史

1. 移动、拖动缩放并旋转四类对象，画布与右侧数值应同步；一次拖动结束后，撤销一次即恢复拖动前状态。
2. 在右侧修改参考点 X/Y、局部宽高和角度，按 Enter 或离开输入框后应立即提交。位置表示局部原点在世界中的位置，局部宽高为旋转前的包围盒尺寸。
3. 修改带孔对象的局部宽度或高度，外轮廓和孔洞应沿对应方向同步缩放，另一个方向的尺寸保持不变。
4. 输入会使图形越界或退化的值，应有提示，实际图形保持原状；修正后可正常提交。
5. 开启移动、缩放吸附，拖动对象及各侧、各角控制点，检查吸附与固定对侧锚点的表现。
6. 多选不同类型对象一起移动，检查各对象之间的位置关系；测试删除、撤销、重做和调整加工顺序。
7. 在项目名称、工作区、网格、几何、加工参数和全局参数输入框中修改值并按 Enter，确认立即应用；中文等输入法尚在组词时按 Enter 不应误提交。

## 加工与保存

1. 开启加工预览。示例采用“填充后轮廓”，扫描行间距为 1 mm。
2. 检查凹入空白、孔洞和分离部分间的空白均没有开启激光的填充路径；跨空白的连接应为空行程。
3. 修改填充角度、间距及轮廓方向，检查预览更新；尝试轮廓、填充、填充后轮廓和轮廓后填充。
4. 分别导出 CSV 和 DBD，确认能够完成保存。
5. 修改形状后保存为新项目，关闭后重开，检查位置、尺寸、角度、孔洞、加工参数和顺序保持一致。
6. 打开 `fixtures/project-v1.example.json`，检查旧矩形和线段仍正常；另存后文件应为版本 2。请保留旧文件，以便继续用旧版软件打开。

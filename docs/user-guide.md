# 使用指南

[返回项目首页](../README.md) · [开发者入口](README.md)

## 从绘图到导出

1. 设置工作区宽高和世界坐标中心，最大宽高均为 190 mm，允许负坐标。
2. 创建线段、矩形、椭圆、多边形或文字；绘制成功后自动回到选择工具。
3. 选中对象，在右侧修改位置、尺寸、角度和加工参数；按 Enter 或离开输入框提交有效数值。
4. 调整右侧加工顺序，导出时严格沿用该顺序。
5. 开启路径预览，确认轮廓、填充和空行程，保存项目后导出设备文件。

网格辅助定位，移动与缩放吸附分别设置。按住中键平移，缩放或使用“适合工作区”检查全图。一次拖动或应用操作可用一次撤销恢复。

## 复制、粘贴与重复

选中一个或多个对象后，使用 Ctrl/Command+C 复制。复制内容保存在当前运行中的 LaserTisch 内，可以新建或打开另一个项目后继续粘贴；关闭软件后不会保留，也不会写入项目文件或系统剪贴板。

Ctrl/Command+V 粘贴剪贴板中的对象，Ctrl/Command+D 直接重复当前选择。执行后，对象组以整体包围框中心跟随光标，保留对象间的相对位置、几何、文字来源、可见与锁定状态及加工参数。开启移动吸附时，放置中心沿用网格吸附。

绿色候选可以单击放置；红色候选表示至少一个对象越过工作区边界，单击不会创建，可继续移动到合法位置。若对象组整体大于当前工作区，则不能开始放置。滚轮缩放和中键平移在放置期间仍可使用，按 Esc 放弃。

只有合法单击才真正创建对象：新对象使用独立标识，追加到对象和加工顺序末尾，多对象保持原有的相对加工顺序。整组放置只产生一次撤销记录；放置前的预览和取消操作不修改项目。

## 线段、矩形与椭圆

线段、矩形和椭圆通过拖动绘制。按住 Shift，线段约束为水平、垂直或 45°，矩形约束为正方形，椭圆约束为正圆。

椭圆是生成矩形的内接椭圆所对应的多边形近似，可设置 **3–1024** 边，默认 **64** 边。边数越多通常越精确，但过多拐点和短线段可能不利于激光加工。

椭圆宽高表示生成矩形的尺寸，低边数时实际轮廓包围盒可能较小。修改边数重新生成近似；转换为普通多边形后可编辑顶点，撤销转换可恢复边数调整。

## 逐点绘制与多边形编辑

选择多边形工具，依次点击三个以上顶点，再点击首点或按 Enter 闭合。Backspace 或撤销退回上一点，Esc 或切换工具取消草稿。闭合失败可继续修正；自交、退化或越界轮廓不能应用。

多边形支持凹形、孔洞和多个分离部分。位置是局部参考点的世界坐标，宽高是旋转前的局部包围盒尺寸；旋转和平移不改变局部顶点。

选中普通多边形后点击“编辑顶点”：

- 点击顶点选择，拖动移动；右侧可输入精确局部坐标并查看世界坐标。
- 双击边插点，或在所选顶点之后插入中点。
- Delete/Backspace 删除所选顶点，每个轮廓至少保留三个顶点。
- 使用轮廓选择器切换外轮廓、孔洞和分离部分。
- Esc 或“完成顶点编辑”退出。无效修改被拒绝，输入框中的删除键仍用于编辑文字。

未闭合草稿和编辑模式本身不写入项目文件。

## 文字

选择文字工具后，点击画布设置起始基线，在面板输入单行内容、选择字体与字号，再点击“预览轮廓”和“应用文字”。绿色预览在应用前不增加加工对象。

软件随附 **Noto Sans CJK SC**，也支持搜索系统字体。启动时静默读取字体；进入文字编辑时若尚未完成，字体选择区域下方显示读取状态。无法读取的个别字体静默跳过，目录可手动刷新。所选字体缺字时明确报错。

内容最多 256 个 Unicode 码点，不提供换行、字间距或高级排版选项。字号对应字体 EM 大小，实际字形高度因字体不同而变化。

应用后仍可修改内容、字体、字号、基线位置和角度，也可移动或旋转。自由拉伸或编辑顶点前，须转换为普通多边形；转换后不能直接编辑内容和字体，可撤销恢复。

### 精度与短线段

字体曲线转换为小段直线。默认轮廓误差 **0.005 mm**，误差越小通常顶点越多。误差指转换取整前的逼近约束，最终坐标仍落在 **0.001 mm** 网格，旋转取整也可能带来小量变化。

“短线段合并目标”默认 **0（关闭）**。启用后，在轮廓误差和孔洞约束允许的情况下，尽量合并短于目标长度的边。

这是软目标，部分短边必须保留，提高目标也可能不改变顶点数。面板显示实际最短边及未达目标数量，相关边以红色显示。进一步减少顶点时，可适当放宽轮廓误差，并放大检查细笔画、尖角和孔洞。

此设置只处理重新生成的文字轮廓，不筛除蛇形填充段，也不会断开轮廓以满足目标。

### 保存与缺失字体

项目保存文字来源与固定多边形轮廓。换电脑或原字体缺失时，仍能显示、填充和导出已有轮廓；重新生成前须明确选择可用字体。打开项目不会自动换字体或重新排版。

示例：[可编辑文字](../fixtures/editable-text-v2.lasertisch.json)、[模拟缺失字体](../fixtures/text-missing-font-v2.lasertisch.json)。后者使用测试身份模拟缺失，不需要卸载本机字体。

## 布尔运算

选中恰好两个可见、未锁定的闭合对象后，属性面板提供布尔运算。支持矩形、椭圆、多边形和文字，线段不能参与。

1. 检查 A/B 名称，选择并集、交集或减除 **A − B**，必要时交换 A/B。
2. 点击“预览结果”，绿色区域表示候选，原对象淡化。
3. 点击“应用运算”，生成普通多边形，结果可包含孔洞和多个分离部分。

默认替换两个原对象，结果继承 A 的加工参数和加工位置。保留原对象时结果插在 A 后面；原对象仍参与加工，避免重复加工时可设为“不加工”。

空结果须额外确认才会移除原对象。取消或只预览不会修改项目，一次撤销恢复整个运算。文字参与运算后，结果是普通多边形，撤销可恢复可编辑文字。

## 加工路径

闭合对象支持轮廓、蛇形填充、填充后轮廓和轮廓后填充，可设置速度、扫描间距、填充角度及轮廓方向。文字使用相同规则，填充跳过字内孔洞，跨孔洞和字间移动时关闭激光。

填充扫描以世界坐标为基准，相邻非空扫描行往返加工。短于 **0.1 mm** 的填充段会被筛除；该规则不删除轮廓短边。线段按起点到终点加工。

每个导出程序先关闭激光并跳转到世界坐标原点，再按对象顺序加工，结束后停留在最后目标点。

## 文件与兼容性

| 文件 | 用途 |
| --- | --- |
| `.lasertisch.json` | 可编辑项目：工作区、图形、文字来源与轮廓、加工参数和顺序 |
| `.csv` | UTF-8 绝对坐标运动指令，含命令、目标坐标和速度 |
| `.dbd` | 目标设备的二进制加工文件 |

当前格式为版本 2，支持打开并迁移版本 1，保存时统一为版本 2。旧版程序不能打开版本 2；较早支持版本 2 的程序也可能不认识文字类型，可先转换为普通多边形后保存。

## 快捷键

macOS 使用 Command 代替 Ctrl。输入框优先处理文字输入。

| 操作 | 快捷键 |
| --- | --- |
| 选择 / 平移 | V / H |
| 线段 / 矩形 / 椭圆 / 多边形 / 文字 | L / R / E / P / T |
| 闭合多边形草稿 | Enter 或点击首点 |
| 撤回草稿上一点 | Backspace 或 Ctrl+Z |
| 适合工作区 | Ctrl+0 |
| 新建 / 打开 / 保存 | Ctrl+N / Ctrl+O / Ctrl+S |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 复制 / 粘贴 / 重复所选对象 | Ctrl+C / Ctrl+V / Ctrl+D |
| 删除对象；顶点模式中删除顶点 | Delete 或 Backspace |
| 取消放置或草稿、退出顶点编辑或返回选择工具 | Esc |
